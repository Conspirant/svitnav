# SVIT NAV — Indoor Campus Navigation

Indoor maps and walking directions for Sai Vidya Institute of Technology.

## Features

- **Interactive Campus Map**: Vector-rendered floorplans with multi-floor navigation.
- **Client-Side A* Pathfinding**: Instant indoor routing between classrooms, labs, elevators, and amenities.
- **Admin Map Editor**: Map editing suite with floorplan drafting, POI placement, and publishing.

## Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- npm or bun

### Installation

```sh
npm install
```

### Development

Run the development server:

```sh
npm run dev
```

### Build

Create an optimized production build:

```sh
npm run build
```
